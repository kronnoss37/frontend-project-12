## 📘 Описание проекта

**Slack Chat** — это веб-приложение для обмена сообщениями в реальном времени, вдохновлённое Slack. Поддерживает регистрацию/авторизацию пользователей, работу с каналами и обмен сообщениями в реальном времени.

После авторизации пользователь может создавать новые каналы, редактировать или удалять существующие и отправлять сообщения, которые мгновенно отображаются у всех участников.

Основной упор сделан на:

- маршрутизацию и навигацию
- real-time взаимодействие
- управление состоянием приложения
- интерактивное взаимодействие пользователя с интерфейсом
- управление формами и валидацию пользовательского ввода
- работу с асинхронными запросами и состояниями загрузки
- обработку ошибок

## ✨ Возможности

- 👤 Регистрация и авторизация пользователей  
- 💬 Отправка и получение сообщений в реальном времени  
- 📢 Создание, редактирование и удаление каналов  
- 🔄 Автоматическое обновление интерфейса  
- ⚠️ Обработка ошибок  
- 🔔 Наличие всплывающих уведомлений при возникновении ошибок или после успешного действия
- 🤬 Фильтрация нецензурных слов

## 🚀 Установка и запуск

```bash
# Clone the repository
git clone https://github.com/kronnoss37/frontend-project-12.git

# Navigate to the project directory
cd frontend-project-12

# Install dependencies for the program to work correctly
make install

# Run dev-server and app in the browser
make app

# Build the project
make build
```
